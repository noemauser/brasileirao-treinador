# Brasileirão — Treinador v12.2

Jogo de técnico de futebol brasileiro (offline, single-file HTML pack).

## Pacote completo (com fotos)
Baixe o ZIP na pasta **Brasileirão** do Google Drive:
- `Brasileirão.zip` ou `Brasileirao_v12.2_final.zip`
- 92 clubes BR + 32 internacionais (TM)
- 3883 fotos de elenco · 124 emblemas

Este repositório guarda o **código-fonte** e logos. As faces completas ficam no Drive (evita repo gigante).

## v12.2
- Copas: Estaduais, Copa do Brasil, Libertadores, Sul-Americana
- NPCs SA/MX com elenco e emblemas oficiais
- Pênaltis no mata-mata, migração de saves, pente fino de bugs

## Como jogar
1. Baixe o ZIP do Drive
2. Extraia
3. Abra `index.html` no navegador
